## 🌿 GitHub Contribution Workflow

Team members who want to make technical changes can contribute through a fork and Pull Request.

### 1. Fork the Repository

Open the project repository on GitHub and select **Fork**.

### 2. Clone Your Fork

```bash
git clone https://github.com/YOUR-USERNAME/Coral-Reef-Skill-Exchange.git
cd Coral-Reef-Skill-Exchange
```

### 3. Create a Branch

```bash
git checkout -b feature/your-feature
```

### 4. Make and Test Your Changes

Make the required changes in your local project and test them before committing.

### 5. Commit the Changes

```bash
git add .
git commit -m "feat: describe your change"
```

### 6. Push the Branch

```bash
git push origin feature/your-feature
```

### 7. Create a Pull Request

Open your fork on GitHub and create a Pull Request targeting the project's `main` branch.

## 🔐 Contribution Rules

Before creating a Pull Request:

- Test your changes locally.
- Keep changes focused on the assigned work.
- Do not overwrite another contributor's work without discussion.
- Do not commit passwords or API keys.
- Do not commit authentication tokens.
- Do not commit `.env` files containing secrets.
- Do not commit the local database.
- Do not commit virtual environments.
- Preserve existing working functionality.
- Include screenshots when making significant UI changes.
- Describe the changes clearly in the Pull Request.
